### 🧭 About Me

```yaml
role: AI/ML Engineer
focus: LLM agent systems · AI search visibility (GEO/AEO) · data pipelines
currently_building: Velova — daily brand monitoring across ChatGPT, Gemini, Claude, Perplexity & Google AI Overviews
default_stack: Next.js + TypeScript on top · Express + Prisma + Postgres underneath · BullMQ for everything slow
also_shipped: EVOS (wedding operations platform) · PitchAI (knowledge-graph pitch generation)
fun_fact: I recovered a live client's database from raw heap pages after a bad cascade delete 🧯
```

I build **AI systems that have to be right every day**, not just impressive in a demo. Most of my
time goes into orchestrated LLM pipelines — multi-agent graphs with checkpointing and durable
resume, retrieval grounded in real customer data, and deterministic scoring layers so the output
is auditable instead of vibes. The other half is the unglamorous part that makes it work:
schema design, queue workers, idempotent backfills, and provenance you can trace back to a
single source URL.
